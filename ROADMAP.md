# Roadmap: kore-master-play

From empty project to a town that lives for years. Each phase ends verifiable.

## Phase 1: Project foundation
- Godot project skeleton, input abstraction, world clock, one district scene, save format v1 with the migration test harness already running.
- Exit test: a character walks a single street through a full day and night cycle; the game saves, closes, and reloads to the same moment.

## Phase 2: The first street
- One complete district: homes, a workshop, gardens; NPC schedules and first dialogue sets as content data; palette and density gates live in the pipeline.
- Exit test: a new festival is added by editing content files only, and it runs in game.

## Phase 3: Town systems
- Gardens and growth, repair and crafting, relationships and memory, town calendar with seasons.
- Exit test: an NPC references, unprompted, an event the player helped with two in-game weeks earlier.

## Phase 4: First public build
- A playable Kore Town demo: one district, one season, one festival; desktop exports; save migration proven against golden saves.
- Exit test: a stranger can download, play an in-game week, and keep their save through an update.

## Phase 5: Growth
- Second and third districts, mobile exports, content pack system, localization scaffolding in use.
- Exit test: a content pack adds a district event with zero changes to existing saves.

## Phase 6: End state
- A living town with years of seasonal content, a creator program where community content packs are reviewed and shipped, and a foundation reusable for future Kore games (a tactics title, a story adventure) without forking the save and content discipline that made the town trustworthy.
